# 小六壬起卦 | Xiao Liu Ren Divination

基于传统小六壬体系的在线起卦工具。

项目以“三宫轨迹分析”为核心，结合六宫象意、五行生克、事项分类、完整宫位转化规则与结构化断语，对问事过程进行多层解读。纯前端实现，无需后端，可直接部署到 GitHub Pages。

🔗 **在线体验**：https://fyapeng.com/xliuren

---

## ✨ 功能特性

### 起卦方式

- **按当前时间**：自动获取公历时间，转换为农历月、日、时辰进行起卦
- **按随机数字**：手动输入三个数字起卦，适用于心中默念随机数的场景

### 三宫轨迹分析

不同于只看最终落宫的简化版本，本工具展示完整三宫信息：

- **第一宫（月上）**：事情的起因与背景
- **第二宫（日上）**：事情的经过与发展
- **第三宫（时上）**：事情的结果与现状

系统会根据三宫之间的递进关系，分析事件从起因、过程到结果的变化路径。

### 分类问事

支持 8 种事项的针对性解读：

- 综合
- 求财
- 婚恋
- 事业
- 出行
- 健康
- 失物
- 争议

每类事项均有独立的解释结构，不再只显示一句固定断语。

### 完整组合规则

系统内置完整二宫转化规则层：

- 6 个宫位
- 36 条二宫转化规则
- 自动覆盖 216 种三宫组合
- 内置若干特殊三宫格局

三宫解读方式为：

```text
第一宫 → 第二宫 → 第三宫
起因   → 经过   → 结果
```

每一卦都会同时分析：

- 第一宫到第二宫的转化
- 第二宫到第三宫的转化
- 三宫整体格局
- 是否命中特殊三宫格

例如：

- 大安 → 速喜 → 小吉：稳喜成合
- 留连 → 赤口 → 空亡：拖争成空
- 赤口 → 小吉：争后转和
- 速喜 → 空亡：先喜后空

### 分层详断

结果报告包含：

- 总体判断
- 三宫轨迹
- 分层事项详断
- 宫位组合象意
- 五行生克分析
- 时辰与落宫关系
- 应对建议
- 方位线索
- 人物线索
- 应期参考

### 五行生克分析

系统分析：

- 起因宫 → 经过宫
- 经过宫 → 结果宫
- 起因宫 → 结果宫
- 当前时辰五行 → 最终落宫五行

据此辅助判断事件发展中的助力、阻力、泄气、受制与比和关系。

当前项目部署在自定义域名路径：

1. 进入仓库 **Settings → Pages**
2. Source 选择 `main` 分支
3. 目录选择 `/ (root)`
4. 保存后等待部署完成

由于项目使用 ES Modules，推荐用本地静态服务器预览，而不是直接双击打开 `index.html`。

例如使用 Python：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 🔧 技术架构

### `index.html`

页面入口，只负责基础结构与加载模块。

### `css/style.css`

页面样式，包含基础布局、三宫卡片、结果报告、五行关系、分层详断和移动端适配。

### `js/lunar.js`

农历与时辰工具。

农历转换基于浏览器原生 API：

```javascript
new Intl.DateTimeFormat('zh-CN-u-ca-chinese', {
  year: 'numeric',
  month: 'long',
  day: 'numeric'
})
```

### `js/core.js`

核心算法与五行逻辑。

起卦算法：

```text
月上宫 = (农历月 - 1) % 6
日上宫 = (月上宫 + 农历日 - 1) % 6
时上宫 = (日上宫 + 时辰序号 - 1) % 6
```

六宫顺序：

```text
大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡
```

### `js/readings/data.js`

结构化断语数据层，包含六宫基础象意、宫位关键词、宫位五行、宫位六神、方位与人物线索、分类事项断语。

### `js/readings/rules.js`

宫位转化规则层。

包含：

- 36 条二宫转化规则
- 三宫组合生成器
- 特殊三宫格局
- 规则覆盖统计

### `js/readings/interpreter.js`

断事解释器。

负责将以下信息组合为结构化报告：

- 第一宫：起因
- 第二宫：经过
- 第三宫：结果
- 所问事项
- 二宫转化规则
- 三宫整体格局
- 五行关系
- 时辰关系

### `js/renderer.js`

页面渲染层，负责将解释器生成的结构化结果渲染为可读报告。

### `js/app.js`

应用入口逻辑，负责事件绑定、起卦输入、当前时间更新、调用核心算法、调用解释器、调用渲染器。

## 📖 小六壬简介

小六壬是中国民间流传的一种简易占卜方法，以大安、留连、速喜、赤口、小吉、空亡六宫按月、日、时顺数来判断吉凶。

本项目不是传统断法的唯一标准版本，而是将小六壬的基础宫位体系、三宫过程观、五行生克关系和现代前端结构化展示结合起来，形成一个便于学习、体验和扩展的在线工具。
