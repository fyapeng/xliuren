# 小六壬起卦 | Xiao Liu Ren Divination

基于传统小六壬体系的在线起卦工具。

项目以“三宫轨迹分析”为核心，结合六宫象意、五行生克、事项分类、完整宫位转化规则、六神推理、动态应期、人物画像、方位场景与结构化断语，对问事过程进行多层解读。纯前端实现，无需后端，可直接部署到 GitHub Pages。

🔗 **在线体验**：https://fyapeng.com/xliuren

---

## ✨ 功能特性

### 起卦方式

- **按当前时间**：自动获取公历时间，转换为农历月、日、时辰进行起卦
- **按随机数字**：手动输入三个数字起卦，适用于心中默念随机数的场景

### 三宫轨迹分析

不同于只看最终落宫的简化版本，本工具展示完整三宫信息：

- **第一宫（月上）**：事情的起因与背景
- **第二宫（日上）**：事情的经过与发展
- **第三宫（时上）**：事情的结果与现状

系统会根据三宫之间的递进关系，分析事件从起因、过程到结果的变化路径。

### 分类问事

支持 8 种事项的针对性解读：

- 综合
- 求财
- 婚恋
- 事业
- 出行
- 健康
- 失物
- 争议

每类事项均有独立的解释结构，不再只显示一句固定断语。

### 完整组合规则

系统内置完整二宫转化规则层：

- 6 个宫位
- 36 条二宫转化规则
- 自动覆盖 216 种三宫组合
- 内置若干特殊三宫格局

### 高级推理层

当前已接入四个高级推理引擎：

- **六神推理**：青龙、玄武、朱雀、白虎、六合、勾陈参与解释，不再只是展示标签
- **动态应期**：结合最终宫速度、过程宫速度、五行关系与评分推断快慢节奏
- **人物画像**：根据事项类型与结果宫六神生成互动对象、贵人、阻力人物等线索
- **方位场景**：结合宫位方位、场所、物象与事项类型生成更细线索

### 分层详断

结果报告包含：总体判断、三宫轨迹、分层事项详断、宫位组合象意、五行生克分析、时辰与落宫关系、高级推理、应对建议、方位线索、人物线索、应期参考。

## 🔧 技术架构

### `js/lunar.js`

农历与时辰工具。农历转换基于浏览器原生 API：

```javascript
new Intl.DateTimeFormat('zh-CN-u-ca-chinese', {
  year: 'numeric',
  month: 'long',
  day: 'numeric'
})
```

### `js/core.js`

核心算法与五行逻辑。

```text
月上宫 = (农历月 - 1) % 6
日上宫 = (月上宫 + 农历日 - 1) % 6
时上宫 = (日上宫 + 时辰序号 - 1) % 6
```

六宫顺序：

```text
大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡
```

### `js/readings/data.js`

结构化断语数据层，包含六宫基础象意、宫位关键词、宫位五行、宫位六神、方位与人物线索、分类事项断语。

### `js/readings/rules.js`

宫位转化规则层，包含 36 条二宫转化规则、三宫组合生成器、特殊三宫格局与规则覆盖统计。

### `js/readings/advanced.js`

高级推理层，包含六神推理、动态应期、人物画像、方位场景四类解释器。

### `js/readings/interpreter.js`

断事解释器，负责将三宫、事项、组合规则、五行关系、六神推理、应期、人物与方位线索整合为结构化报告。

### `js/renderer.js`

页面渲染层，负责将解释器生成的结构化结果渲染为可读报告。

### `js/app.js`

应用入口逻辑，负责事件绑定、起卦输入、当前时间更新、调用核心算法、调用解释器、调用渲染器。

## 🧠 自然语言问事规划

自然语言问事不建议一开始就强依赖 LLM API。

推荐路线：

1. **本地关键词识别**：先根据用户输入识别事项类别，如求财、婚恋、事业、出行、失物等
2. **规则增强**：针对“复合、面试、考试、合作、找人、回款”等常见子类建立本地规则
3. **可选 LLM 层**：后续再接入 LLM API，用于理解复杂问题、改写解释、生成更自然的报告
4. **规则为主，LLM 为辅**：核心吉凶、宫位、五行、应期仍由本地规则决定，LLM 只负责语义识别与语言组织

这种设计可以避免 API 成本、隐私风险和不可控输出，同时保留未来增强空间。
